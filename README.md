# BookNook

BookNook is a small online library: add a book, borrow a book, return a book.

**Live site:** https://booknook-client-sandy.vercel.app

## Features
- Email/password and Google authentication with BetterAuth
- Browse all books and see the 6 newest arrivals on the home page
- Add, edit and delete your own books, with image upload
- Borrow a book for 7 days and return it from My Borrows
- Available copies tracking and no double borrowing
- JWT protected API, private routes and a custom 404 page
- Responsive design for mobile, tablet and desktop

## Tech
Next.js, DaisyUI, BetterAuth, Express, MongoDB, Swiper
